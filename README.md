# Exercise 5 — Multi-chart page

Open `index.html` through a local web server such as VS Code Live Server so D3 can load the CSV files. The page presents Exercises 5.1–5.3 on one page.

The `data` folder includes the source CSV files and generated chart summaries. Run `python data/prepare-data.py` to regenerate the TV summaries. Exercise 5.3 uses available TV models sold in Australia, grouped as Small < 42 inches, Medium 42–65 inches, and Large > 65 inches.
